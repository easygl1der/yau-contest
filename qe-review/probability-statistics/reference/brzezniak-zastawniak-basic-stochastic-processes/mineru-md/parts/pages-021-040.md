# Conditional Expectation

Conditional expectation is a crucial tool in the study of stochastic processes. It is therefore important to develop the necessary intuition behind this notion, the definition of which may appear somewhat abstract at first. This chapter is designed to help the beginner by leading him or her step by step through several special cases, which become increasingly involved, culminating at the general definition of conditional expectation. Many varied examples and exercises are provided to aid the reader's understanding.

## 2.1 Conditioning on an Event

The first and simplest case to consider is that of the conditional expectation $E \left( \xi | B \right)$ of a random variable ξ given an event B.

## Definition 2.1

For any integrable random variable ξ and any event $B \in { \mathcal { F } }$ such that $P ( B ) \neq 0$ the conditional expectation of ξ given B is defined by

$$
E ( \xi | B ) = \frac { 1 } { P ( B ) } \int _ { B } \xi \ d P .
$$

## Example 2.1

Three coins, 10p, 20p and 50p are tossed. The values of those coins that land heads up are added to work out the total amount ξ. What is the expected total $\xi .$ amount ξ given that two coins have landed heads up?

Let B denote the event that two coins have landed heads up. We want to find $E \left( \xi | B \right)$ . Clearly, B consists of three elements,

$$
B = \left\{ { \mathrm { H H T } } , { \mathrm { H T H } } , { \mathrm { T H H } } \right\} ,
$$

each having the same probability $\frac { 1 } { 8 }$ . (Here H stands for heads and T for tails.) The corresponding values of $\xi$ are

$$
\begin{array} { r } { \xi ( \mathrm { H H T } ) \ = \ 1 0 + 2 0 = 3 0 , } \\ { \xi ( \mathrm { H T H } ) \ = \ 1 0 + 5 0 = 6 0 , } \\ { \xi ( \mathrm { T H H } ) \ = \ 2 0 + 5 0 = 7 0 . } \end{array}
$$

Therefore

$$
E \left( \xi | B \right) = { \frac { 1 } { P ( B ) } } \int _ { B } \xi \ d P = { \frac { 1 } { \frac { 3 } { 8 } } } \left( { \frac { 3 0 } { 8 } } + { \frac { 6 0 } { 8 } } + { \frac { 7 0 } { 8 } } \right) = 5 3 { \frac { 1 } { 3 } } .
$$

## 2.2 Conditioning on a Discrete Random Variable

The next step towards the general definition of conditional expectation involves conditioning by a discrete random variable n with possible values $y _ { 1 } , y _ { 2 } , . . .$ . such that $P \left\{ \eta = y _ { n } \right\} \ne 0$ for each n. Finding out the value of $\eta$ amounts to finding out which of the events $\{ \eta = y _ { n } \}$ has occurred or not. Conditioning by η should therefore be the same as conditioning by the events $\{ \eta = y _ { n } \}$ . Because we do not know in advance which of these events will occur, we need to consider all possibilities, involving a sequence of conditional expectations

$$
E \left( \xi | \left\{ \eta = y _ { 1 } \right\} \right) , E \left( \xi | \left\{ \eta = y _ { 2 } \right\} \right) , \ldots .
$$

A convenient way of doing this is to construct a new discrete random variable constant and equal to $E \left( \xi | \left\{ \eta = y _ { n } \right\} \right)$ on each of the sets $\{ \eta = y _ { n } \}$ . This leads us to the next definition.

## Definition 2.2

Let ξ be an integrable random variable and let η be a discrete random variable as above. Then the conditional expectation of ξ given η is defined to be a random variable $E ( \xi | \eta )$ such that

$$
E ( \xi | \eta ) ( \omega ) = E ( \xi | \{ \eta = y _ { n } \} ) \quad { \mathrm { i f ~ } } \eta ( \omega ) = y _ { n }
$$

for any $n = 1 , 2 , \ldots { } .$

## Proposition 2.1

If ξ is an integrable random variable and n is a discrete random variable, then

1) $E \left( \xi | \eta \right)$ is $\sigma \left( \eta \right)$ -measurable;

For any $A \in \sigma \left( \eta \right)$

$$
\int _ { A } E ( \xi | \eta ) d P = \int _ { A } \xi d P .\tag{2.1}
$$

Proof

Suppose that'n has pairwise distinct values $y _ { 1 } , y _ { 2 } , \ldots$ Then the events

$$
\left\{ \eta = y _ { 1 } \right\} , \left\{ \eta = y _ { 2 } \right\} , . . .
$$

are pairwise disjoint and cover Ω. The σ-field $\sigma \left( \eta \right)$ is generated by these events, in fact every $A \in \sigma \left( \eta \right)$ is a countable union of sets of the form $\{ \eta = y _ { n } \}$ . Because $E \left( \xi | \eta \right)$ is constant on each of these sets, it must be $\sigma \left( \eta \right)$ -measurable.

For each n we have

$$
\begin{array} { r l } { \displaystyle \int _ { \{ \eta = y _ { n } \} } E ( \xi | \eta ) d P = \int _ { \{ \eta = y _ { n } \} } E ( \xi | \{ \eta = y _ { n } \} ) d P } & { } \\ { \displaystyle } & { = \int _ { \{ \eta = y _ { n } \} } \xi d P . } \end{array}
$$

Since each $A \in \sigma ( \eta )$ is a countable union of sets of the form $\{ \eta = y _ { n } \}$ , which are pairwise disjoint, it follows that

$$
\int _ { A } E ( \xi | \eta ) d P = \int _ { A } \xi d P ,
$$

as required.

## 2.3 Conditioning on an Arbitrary Random Variable

Properties 1) and 2) in Proposition 2.1 provide the key to the definition of the conditional expectation given an arbitrary random variable η.

## Definition 2.3

Let ξ be an integrable random variable and let η be an arbitrary random ${ \pmb \xi }$ variable. Then the conditional expectation of ξ given η is defined to be a random ${ \pmb \xi }$ $\eta$ variable $E ( \xi | \eta )$ such that

1) $E \left( \xi | \eta \right)$ is $\sigma \left( \eta \right)$ -measurable;

For any $A \in \sigma \left( \eta \right)$

$$
\int _ { A } E ( \xi | \eta ) d P = \int _ { A } \xi d P .
$$

## Remark 2.1

We can also define the conditional probability of an event $A \in { \mathcal { F } }$ given n by

$$
P ( A | \eta ) = E \left( 1 _ { A } | \eta \right) ,
$$

where ${ \bf 1 } _ { A }$ is the indicator function of A.

Do the conditions of Definition 2.3 characterize $E \left( \xi | \eta \right)$ uniquely? The lemma below implies that $E \left( \xi | \eta \right)$ is defined to within equality on a set of full measure. Namely,

$$
{ \mathrm { i f ~ } } \xi = \xi ^ { \prime } { \mathrm { ~ a . s . , ~ t h e n ~ } } E \left( \xi | \eta \right) = E \left( \xi ^ { \prime } | \eta \right) { \mathrm { ~ a . s . } }\tag{2.2}
$$

The existence of $E \left( \xi | \eta \right)$ will be discussed later in this chapter.

Lemma 2.1

Let $( \Omega , { \mathcal { F } } , P )$ be a probability space and let $\mathscr { G }$ be a σ-field contained in $\mathcal { F }$ If ξ is a G-measurable random variable and for any $B \in { \mathfrak { G } }$

$$
\int _ { B } \xi d P = 0 ,
$$

then $\xi = 0$ a.s.

Proof

Observe that $P \left\{ \xi \ge \varepsilon \right\} = 0$ for any $\varepsilon > 0$ because

$$
0 \leq \varepsilon P \left\{ \xi \geq \varepsilon \right\} = \int _ { \{ \xi \geq \varepsilon \} } \varepsilon d P \leq \int _ { \{ \xi \geq \varepsilon \} } \xi d P = 0 .
$$

The last equality holds, since $\{ \xi \geq \varepsilon \} \in { \mathcal { G } }$ .Similarly, $P \left\{ \xi \le - \varepsilon \right\} = 0$ for any $\varepsilon > 0$ . As a consequence,

$$
P \left\{ - \varepsilon < \xi < \varepsilon \right\} = 1
$$

for any $\varepsilon > 0$

Let us put

$$
A _ { n } = \left\{ - { \frac { 1 } { n } } < \xi < { \frac { 1 } { n } } \right\} .
$$

Then $P \left( A _ { n } \right) = 1$ and

$$
\{ \xi = 0 \} = \bigcap _ { n = 1 } ^ { \infty } A _ { n } .
$$

Because the $A _ { n }$ form a contracting sequence of events, it follows that

$$
P \{ \xi = 0 \} = \operatorname* { l i m } _ { n  \infty } P ( A _ { n } ) = 1 ,
$$

as required.

One difficulty involved in Definition 2.3 is that no explicit formula for $E \left( \xi | \eta \right)$ is given. If such a formula is known, then it is usually fairly easy to verify conditions 1) and 2). But how do you find it in the first place?
