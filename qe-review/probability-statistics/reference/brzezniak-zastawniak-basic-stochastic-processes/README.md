## What this book is for in the QE package

Working reference for **Brownian motion / Wiener process** (Chapter 6, Definition 6.9) and the discrete-time martingale / Markov-chain chapters that precede it. The Qiuzhen syllabus still lists Durrett as the official probability book.

**Galton–Watson branching processes.** Not a separate chapter. They appear as a Markov chain on \(\{0,1,2,\dots\}\) in Chapter 5: Exercise 5.11 (branching process / Vugiel), Exercise 5.12 (binomial and Poisson offspring), Proposition 5.6 (Poisson extinction), Remark 5.2 (general mean). Durrett 4.1 §5.3.4 is the matching generating-function writeup.
