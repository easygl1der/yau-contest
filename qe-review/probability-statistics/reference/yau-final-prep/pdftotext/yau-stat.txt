Definition 1.1 (Probability Space). A probability space is a triple (Ω, F, P ) where:

    • Ω is the sample space (set of all possible outcomes)

    • F is a σ-algebra on Ω (collection of events)

    • P : F → [0, 1] is a probability measure satisfying:

         1. P (Ω) = 1
                                                       ∪∞            ∑∞
         2. For disjoint events A1 , A2 , . . .: P (    i=1 Ai ) =    i=1 P (Ai )

Definition 1.2 (Random Variable). A random variable X on probability space (Ω, F, P )
is a measurable function X : Ω → R, i.e., for all Borel sets B ∈ B(R):

                              X −1 (B) = {ω ∈ Ω : X(ω) ∈ B} ∈ F

Definition 1.3 (Distribution Function). The cumulative distribution function (CDF) of
random variable X is:

                           FX (x) = P (X ≤ x) = P ({ω : X(ω) ≤ x})

    Properties of CDF:

    1. FX is non-decreasing

    2. FX is right-continuous

    3. limx→−∞ FX (x) = 0 and limx→∞ FX (x) = 1

    4. P (a < X ≤ b) = FX (b) − FX (a)

Definition 1.7 (Independence of Random Variables). Random variables X and Y are
independent if for all Borel sets A, B:

                         P (X ∈ A, Y ∈ B) = P (X ∈ A)P (Y ∈ B)

Definition 1.27 (Counting Process). A stochastic process {N (t), t ≥ 0} is a counting

    1. N (t) ≥ 0 and N (t) is integer-valued

Definition 1.29 (Stationary Increments). A process has stationary increments if the
distribution of N (t + s) − N (s) depends only on t, not on s.

Definition 1.30 (Poisson Process). A counting process {N (t), t ≥ 0} is a Poisson process
with rate λ > 0 if:

    1. N (0) = 0

    2. Independent increments

    3. Stationary increments

    4. P (N (h) = 1) = λh + o(h)

    5. P (N (h) ≥ 2) = o(h)

    Equivalently: N (t) ∼ Poisson(λt) and increments are independent.

rate λ:

    1. Inter-arrival times T1 , T2 , . . . are i.i.d. Exp(λ)

    2. E[N (t)] = Var(N (t)) = λt

    3. Memoryless property: P (T > s + t|T > s) = P (T > t)

    4. Superposition: Independent Poisson processes with rates λ1 , λ2 combine to rate
       λ 1 + λ2

    5. Thinning: Each event kept with probability p gives rate pλ

    6. Order statistics: Given N (t) = n, the arrival times are distributed as order
       statistics of n uniform random variables on [0, t]

4.3 Suﬀicient Statistics
Definition 4.5 (Suﬀicient Statistic). A statistic T (X) is suﬀicient for parameter θ if the
conditional distribution of X given T (X) = t does not depend on θ.
   Equivalently, by the Factorization Theorem, T (X) is suﬀicient if and only if:
                                      f (x; θ) = g(T (x); θ) · h(x)
where g depends on x only through T (x) and h does not depend on θ.
Theorem 4.4 (Rao-Blackwell Theorem). Let θ̂ be any unbiased estimator of θ with finite
variance, and let T be a suﬀicient statistic for θ. Define:
                                               θ̂∗ = E[θ̂|T ]
    Then:
    1. θ̂∗ is unbiased: E[θ̂∗ ] = θ
    2. θ̂∗ has smaller variance: Var(θ̂∗ ) ≤ Var(θ̂)
    3. θ̂∗ depends on the data only through T
Definition 4.6 (Minimal Suﬀicient Statistic). A suﬀicient statistic T is minimal suﬀicient
if, for any other suﬀicient statistic T ′ , there exists a function f such that T = f (T ′ ) almost
everywhere.
Definition 4.7 (Complete Statistic). A statistic T is complete for the family {Pθ : θ ∈ Θ}
if:
           Eθ [g(T )] = 0 for all θ ∈ Θ =⇒ Pθ (g(T ) = 0) = 1 for all θ ∈ Θ
for any measurable function g such that Eθ [|g(T )|] < ∞.
Theorem 4.5 (Lehmann-Scheffé Theorem). If T is a complete and suﬀicient statistic for
θ, then there exists a unique unbiased estimator of θ based on T , and this estimator is the
Uniformly Minimum Variance Unbiased Estimator (UMVUE).
