4.4. Introduction to Hypothesis Testing.

Definition 4.5 (Hypothesis Test).       • Null hypothesis: H0
    • Alternative hypothesis: H1
    • Test statistic: T (X)
    • Critical region: C
    • Decision rule: Reject H0 if T (X) ∈ C

                              7. Sufficiency (Chapter 7)
7.1. Suﬀicient Statistics.
Definition 7.1 (Suﬀicient Statistic). T (X) is suﬀicient for θ if the conditional distribution
of X given T (X) does not depend on θ.
Theorem 7.1 (Factorization Theorem). T (X) is suﬀicient for θ if and only if:
                                 f (x; θ) = g(T (x); θ) · h(x)
where g depends on x only through T (x) and h doesn’t depend on θ.
7.2. Minimal Suﬀiciency and Completeness.
Definition 7.2 (Minimal Suﬀicient Statistic). T is minimal suﬀicient if for any other
suﬀicient statistic T ′ , there exists a function f such that T = f (T ′ ).
Definition 7.3 (Complete Statistic). T is complete if E[g(T )] = 0 for all θ implies
P (g(T ) = 0) = 1 for all θ.
Theorem 7.2 (Rao-Blackwell Theorem). If θ̂ is unbiased for θ and T is suﬀicient, then
θ̂∗ = E[θ̂|T ] satisfies:
    (1) E[θ̂∗ ] = θ (unbiased)
    (2) Var(θ̂∗ ) ≤ Var(θ̂)
Theorem 7.3 (Lehmann-Scheffé Theorem). If T is complete and suﬀicient, then there
exists a unique UMVUE based on T .

    (3) Then ψ(Y1 ) is the unique MVUE of g(θ)

automatically the unique MVUE.

9.13. Practical Guidelines.
   (1) Choosing Tests:
         • Use t-test when σ unknown and n small
         • Use z-test when σ known or n large
         • Use F-test for comparing variances or in ANOVA
         • Use χ2 -test for categorical data or goodness-of-fit
   (2) Sample Size Considerations:
         • CLT applies for n ≥ 30 (rule of thumb)
         • For t-tests, small sample assumptions require normality
         • ANOVA requires equal variances (Bartlett’s or Levene’s test)
   (3) Model Assumptions:
         • Independence: Crucial for all procedures
         • Normality: Required for exact results, less critical for large n
         • Equal variances: Important for pooled procedures
         • Linearity: Essential for regression models
