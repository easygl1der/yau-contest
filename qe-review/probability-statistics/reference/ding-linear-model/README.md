# Peng Ding — *Linear Model and Extensions* (应用回归分析)

[← Probability & Statistics references](../README.md) · [Provenance](./SOURCE.md) · [arXiv:2401.00649](https://arxiv.org/abs/2401.00649)

Berkeley STAT “Linear Model” notes, later the English monograph. The Chinese course title is **应用回归分析**. Author: Peng Ding, Department of Statistics, UC Berkeley.

This is the **full book** on the QE shelf. The CAM folder of the same name is only the vector-calculus / OLS-gradient excerpt used for 2026 Spring CAM P3.
