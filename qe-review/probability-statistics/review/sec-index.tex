\section{Minimal script check}
\label{sec:check}

Write the following without opening a draft, then do the corresponding paper.

\begin{itemize}
    \item Linear model: \(Y=Z\beta+\varepsilon\); \(\hat\beta\); estimability; Gauss--Markov in four lines; \(I(\beta)=Z^{\top}Z/\sigma^{2}\); the constrained \(\hat\theta_{1}\); a \(t\) interval; Scheff\'e; extra-sum-of-squares \(F\).
    \item Estimation: MoM map \(\mu(\hat\theta)=\bar X\); Fisher \(I(\theta)\); Wald interval; invert a UMP family.
    \item Named families: \(\chi^{2}\), \(t\), \(F\), Beta as a Gamma ratio.
    \item Poisson: two equivalent definitions; waits from \(\{N(t)=0\}\); conditional uniformity density \(n!/t^{n}\); thinning.
    \item Markov: \(\pi P=\pi\); the representation theorem both ways; one sentence on the hypercube chain; generation-chain transience on a \(d\)-regular tree.
    \item Testing: Neyman--Pearson; Karlin--Rubin; the two normal likelihood ratios; \(\Lambda=-2\log\lambda\Rightarrow\chi^{2}_{r}\); one reason Wilks fails.
    \item Bayes: Beta--Binomial, Gamma--Poisson, and the normal--normal precision update; \(L_{2}\) vs \(L_{1}\); Basu in one sentence.
    \item Exponential family: \((\eta,T,A)\); \(\nabla A=\mathbb{E}T\); completeness.
    \item CF CLT: L\'evy continuity; how \(a_{n}\) is read from \(1-\phi(t)\).
    \item Modes: products in probability; one \(L^{1}\) counter-example.
    \item BM: \(e^{uB_{t}-u^{2}t/2}\); Laplace of one-sided \(T_{a}\).
    \item Tails / extremes: exponential tail \(\Leftrightarrow\) MGF; \(M_{n}/\log n\to 1\) for i.i.d.\ exponentials.
\end{itemize}
