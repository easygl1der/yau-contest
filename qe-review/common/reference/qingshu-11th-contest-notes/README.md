# 清疏《大学生数学竞赛班第十一届讲义》

[← common references](../README.md) · [目录](./structure.md) · [Provenance](./SOURCE.md)

Canonical local copy: [清疏大学生数学竞赛班第十一届讲义.pdf](./清疏大学生数学竞赛班第十一届讲义.pdf) (1028 pp., decrypted, 2024-10-28).

This is the shared analysis / linear-algebra / ODE contest notes used by CAM and by probability-statistics (e.g. harmonic sums, MVT, Stolz, Euler–Maclaurin). It is **not** a probability textbook.

## How to read

1. Jump by chapter in [structure.md](./structure.md) (PDF page numbers from bookmarks).
2. If a formula in a QE solution needs a citable excerpt, slice those pages with pypdf; do **not** MinerU the whole file.
3. Existing slices for 2026-spring Prob-Stat Problem 3: [`qingshu-lagrange-mvt`](../../../probability-statistics/reference/qingshu-lagrange-mvt/).
