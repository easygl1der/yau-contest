# S. S.-T. Yau College Student Mathematics Contest Materials

This directory contains Yau Contest materials relevant to preparation in Computational and Applied Mathematics. The Semifinal Written Examination and Final Interview are distinct stages; problem statements, transcriptions, and solutions are stored separately.

- Semifinal Written Examination: sourced from a local historical problem archive; the original upstream release pages remain to be catalogued individually.
- Final Interview: sourced from the 2012--2025 archived ZIP files on the [official related download page](https://yau-contest.com/lists-jxxg.html).
- The 2026 Final Interview problems are not present in the current official archive; participant lists or announcements cannot substitute for the problem statements.
- There are currently 61 items, and all 61 have MinerU reading transcripts.
