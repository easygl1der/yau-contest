# Computational and Applied Mathematics QE Problem Archive: Obsidian Index (English Edition)

This directory is the English edition of the original `notes/` collection. It preserves the same folder and file layout while presenting the public Computational and Applied Mathematics PhD Qualifying Examination (QE) papers from Qiuzhen College, Tsinghua University, together with traceable source records. The current official examination-resources page lists six terms from Fall 2023 through Spring 2026; no earlier public QE papers in this direction were found. This page was updated on 2026-07-28.

## Reading Conventions

- Original examination PDFs are in `../sources/exams/`; each complete MinerU transcription package is in `../transcripts/mineru/`.
- Problem notes use MinerU's LaTeX Markdown directly, rather than plain-text code blocks; the original paper remains authoritative for formulas, matrices, figures, and recognition ambiguities.
- Pedagogical reference solutions by problem are being added incrementally in [`../solutions/`](../solutions/). Problem statements and solutions are deliberately separated: the original papers and MinerU transcriptions retain the problem evidence, while solutions can be independently reviewed, expanded with links back to examinable topics, and supplied with textbook citations.
