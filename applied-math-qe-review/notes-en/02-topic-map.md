# Syllabus and Historical Problem-Type Map

This table connects the official syllabus with the archived examination papers. It is a study-navigation aid, not a substitute for complete theoretical notes; use the [[README|index]] to enter the appropriate term for particular problems.

| Syllabus Module | Representative Signals in Historical Problems |
| --- | --- |
| Interpolation and approximation | Chebyshev polynomials, Lagrange bases, spectral differentiation, Gauss quadrature |
| Nonlinear equations | Newton, secant/quasi-Newton methods, fixed-point iteration, order of convergence |
| Numerical linear algebra | QR, optimal low-rank approximation by SVD, Gauss--Seidel, CG, generalized eigenvalues |
| Ordinary differential equations | Stiffness, stability, three-step/multistep schemes |
| Partial differential equations | Difference schemes, stability, truncation error, maximum principles, boundary layers |
| Asymptotics and modeling | Rayleigh oscillators, composite expansions, dimensional/asymptotic analysis |
| Optimization | Convexity, linear programming, iterative methods |
