# 大纲与历年题型地图

本表用于把官方大纲与已归档试卷连接起来。它是复习导航，不代替完整理论讲义；具体题目可由 [[README|索引]] 进入相应学期。

| 考纲模块 | 历年题目中的代表信号 |
| --- | --- |
| 插值与逼近 | Chebyshev 多项式、Lagrange 基、谱微分、Gauss 求积 |
| 非线性方程 | Newton、割线/拟 Newton、不动点迭代、收敛阶 |
| 数值线性代数 | QR、SVD 最优低秩近似、Gauss--Seidel、CG、广义特征值 |
| 常微分方程 | 刚性、稳定性、三步/多步格式 |
| 偏微分方程 | 差分格式、稳定性、截断误差、最大值原理、边界层 |
| 渐近与建模 | Rayleigh 振子、复合展开、量纲/渐近分析 |
| 最优化 | 凸性、线性规划、迭代法 |


## 下一层资料的写作顺序

后续完整复习书应先从 [[01-syllabus|考纲]] 建立章节覆盖表，再按“动机、定义、定理、完整推导、例题、真题解答、考前检查”扩写。每个结论应链接回本目录的原卷，并在近邻处给出教材或论文引用。
