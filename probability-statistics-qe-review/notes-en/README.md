# Obsidian Index: Probability and Statistics PhD QE Archive

This English edition preserves the transcripts and traceable sources for the Probability and Statistics PhD Qualifying Examination (QE) papers published by Tsinghua University's Qiuzhen College. The official examination-question resource currently lists six semesters, from Fall 2023 through Spring 2026; no earlier public QE papers in this subject area were found. This page was updated on 2026-07-28.

## Reading Conventions

- Source PDFs are in `../sources/exams/`; each full MinerU transcription package is in `../transcripts/mineru/`.
- The question notes use MinerU's LaTeX Markdown directly, rather than plain-text code blocks. Where formulas, matrices, figures, or OCR are ambiguous, consult the source PDF.
- The [`../solutions/`](../solutions/) directory is incrementally adding pedagogical, problem-by-problem reference solutions. The questions and solutions remain deliberately separate: source papers and MinerU transcriptions preserve the evidence for each problem, while solutions may be reviewed independently and extended with topic links and textbook citations.
