# 大纲与历年题型地图

本表用于把官方大纲与已归档试卷连接起来。它是复习导航，不代替完整理论讲义；具体题目可由 [[README|索引]] 进入相应学期。

| 考纲模块 | 历年题目中的代表信号 |
| --- | --- |
| 概率基础与分布 | 极值、条件分布、多元 Gaussian、特征/生成函数 |
| 收敛与极限定理 | LLN、CLT、渐近正态、triangular arrays |
| 条件期望与鞅 | 停时、可选停时、鞅性质、随机游走 |
| 随机过程 | Brownian motion、Poisson process、Markov/branching process |
| 统计推断 | MLE、Bayes 规则、置信区间、充分性与完备性 |
| 假设检验 | UMP、GLRT、Neyman--Pearson、Karlin--Rubin |
| 大样本与线性模型 | Delta method、渐近分布、相关系数、回归推断 |


## 下一层资料的写作顺序

后续完整复习书应先从 [[01-syllabus|考纲]] 建立章节覆盖表，再按“动机、定义、定理、完整推导、例题、真题解答、考前检查”扩写。每个结论应链接回本目录的原卷，并在近邻处给出教材或论文引用。
