# Probability problems: team contest

## May 2019

1. Let Z be a real random variable, the log Laplace transform of Z is the function taking values in R ∪ $\{ \infty \}$ defined for $\lambda \in \mathbb { R }$ by:

$$
\Psi_ {Z} (\lambda) = \ln \operatorname{E} (\exp (\lambda Z)).
$$

1-1 For Z a random variable taking value in a bounded interval I, derive twice $\Psi _ { Z }$ and identify, for all $\lambda ,$ this second derivative to the variance of a random variable $Z _ { \lambda }$ , which we precise its distribution.

1-2 If Z is a random variable taking value in a bounded interval I, show that the variance of $Z$ is upper bounded by $| I | ^ { 2 } / 4$

1-3 If Z is a random variable taking value in a bounded interval I. Show that for all $\lambda \in \mathbb { R } ^ { + }$

$$
\Psi_ {Z} (\lambda) \leq \frac {| I | ^ {2} \lambda^ {2}}{8}.
$$

1-4 Let $Z _ { 1 } , \ldots , Z _ { n }$ be intendant random variables, such that $Z _ { i }$ take value in $[ a _ { i } , b _ { i } ]$ ; denote $Z = \textstyle \sum Z _ { i }$ and $\tilde { Z } = Z - \operatorname { E } ( Z )$ . Show that

$$
\Psi_ {\tilde {Z}} (\lambda) \leq \frac {\lambda^ {2}}{8} \sum (b _ {i} - a _ {i}) ^ {2}.
$$

1-5 With same notations as in 1-4, show that for all $\epsilon > 0$ 2

$$
\mathbf {P} (| \tilde {Z} | \geq \epsilon) \leq 2 \exp (- \frac {2 \epsilon^ {2}}{\sum (b _ {i} - a _ {i}) ^ {2}}).
$$

2. Let $\{ X _ { n } \}$ be independent indentically distributed random variables with finite mean, and $S _ { n } =$ $\textstyle \sum _ { i = 1 } ^ { n } X _ { i }$ be the partial sum. Show that the sequence $\{ S _ { n } / n \}$ is a reverse martingale. This means that

$$
\mathbb {E} \left[ \frac {S _ {n}}{n} \Big | \mathcal {F} _ {n + 1} \right] = \frac {S _ {n + 1}}{n + 1},
$$

where

$$
\mathcal {F} _ {n} = \sigma \{S _ {n}, S _ {n + 1}, \dots \}
$$

is the smallest σ-algebra generated by the random variables $S _ { k }$ for $k \geq n$

3. Let $n \geq 2$ be an integer, show that, a random vector $X \in \mathbb { R } ^ { n }$ having independent components and its distribution is $O ( n )$ invariant i.f.f. $X \sim { \mathcal { N } } ( 0 , \sigma ^ { 2 } )$

(Distribution is $O ( n )$ invariant means that for any orthogonal matrix, that is a rotation, $P \in O ( n )$ X and P X have the same distribution.)
