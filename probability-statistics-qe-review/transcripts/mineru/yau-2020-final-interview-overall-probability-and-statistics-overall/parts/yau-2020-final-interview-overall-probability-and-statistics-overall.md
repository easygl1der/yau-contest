PROBLEM 1. Let $\left\{ X _ { n } \right\}$ be a sequence of independent, identically distributed random variables taking values in $\mathbb { N } ,$ the set of positive integers. Define

$$

$$

i.e., $R _ { n }$ is the number of distinct integers in the set $\{ X _ { 1 } , \cdots , X _ { n } \}$ . Suppose that $\mathbb { E } [ X _ { 1 } ] < \infty$ . Prove that $R _ { n } / \sqrt { n } \to 0$ in probability.
